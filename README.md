# Deryanova

Parent-oriented information website about baby development and the first year of life, covering monthly milestones, the STIKO vaccination schedule and general parenting guidance. The content is written in German.

## Contents

- Month-by-month overview of the first year
- Vaccination schedule based on the German STIKO recommendations
- General parenting guidance

## Getting Started

Open `index.html` in a browser, or serve the folder with a static server:

```bash
python3 -m http.server 8000
```
